# BiblioBot

## Que es?

Se trata del desarrollo de una pagina web la cual estara tanto para clientes como trabajadores de una biblioteca, en esta pagina web se podran realizar compras de libros, como cualquier biblioteca normal, pero tambien permitira a los trabajadores realizar diferentes acciones propias del negocio como hacer solicitudes para comprar libros, registrar la entrada del inventario, hacer solicitudes para traslados de una sede a otra, buscar los titulos disponibles en la biblioteca, registrar ventas. Ademas esta pagina tambien permitira el acceso a clientes, el cliente podra principalmente reaizar la compra de libros, ver los libros disponibles, listarlos por diferentes generos, revisar las compras que ha hecho, basicamente lo que tendria un ecomerce para comprar libros.
Ade,as de esto, dentro de la biblioteca habra un chatbot integrado en ella para poder realizar las acciones que se describen arriba, ademas el chatbot podra realizar acciones como responder preguntas, realizar tareas, etc. Lo que podra hacer el chatbot es consumir los enpoints del backend para realizar las mismas acciones que se puedan hacer pero por medio de su interfaz de chat entonces si el usuario esta en el chatbot, el usuario podra realizar las mismas acciones que el bot, por ejemplo si el cliente quiere comprar un libro, el bot podra responder la pregunta de que tipo de libro quiere comprar, luego el usuario podra responder la opcion de libro de ficcion, o de historia, etc y el bot podra comprar el libro y enviar la informacion de la compra a la biblioteca para que la gestione. Lo mismo aplica para el resto de acciones, por ejemplo si un trabajador quiere solicitar el traslado de 50 libros de un titulo de una sede a otra, el trabajador puede hacer una solicitud, y el bot respondera la misma y enviara la solicitud a la biblioteca, la biblioteca podra procesar la solicitud y realizar el traslado.
## Funciones
El bot podra hacer edicion de la base de datos(Esto lo hara haciendo utilizando los endpoints del backend). POr ejemplo si el trabajador le envia un mensaje diciendo "Llegaron 50 libros de el titulo "La iliada" por favor registra la entrada, el bot respondera "si, registraré la entrada" y el trabajador respondera "si" y el bot respondera "ok" y luego el bot registrara la entrada en la base de datos por medio de los endpoints del backend. Si el cliente quiere comprar un libro, el bot podra responder la pregunta de que tipo de libro quiere comprar, luego el usuario podra responder la opcion de libro de ficcion, o de historia, etc y el bot podra comprar el libro y enviar la informacion de la compra a la biblioteca para que la gestione. Lo mismo aplica para el resto de acciones, por ejemplo si un trabajador quiere solicitar el traslado de 50 libros de un titulo de una sede a otra, el trabajador puede hacer una solicitud, y el bot respondera la misma y enviara la solicitud a la biblioteca, la biblioteca podra procesar la solicitud y realizar el traslado.
